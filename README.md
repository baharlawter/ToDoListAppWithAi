# Daylight To-do List

A responsive React to-do list frontend. Tasks can be added, completed, deleted, filtered, and cleared after completion. The current version saves tasks in the browser with `localStorage`; a future Spring Boot API can replace that storage layer.

## Run locally

Install [Node.js](https://nodejs.org/) if it is not already installed, then run:

```sh
npm install
npm run dev
```

To create a production build:

```sh
npm run build
```
